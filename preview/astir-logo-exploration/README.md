## Validation and limits

The native-rendered artwork and iPhone comparison sheets were inspected during exploration. Static page wiring, file references, source preservation, PNG dimensions/alpha, SVG references, package CRC/hashes, and JavaScript syntax were checked. Interactive desktop/mobile browser behavior was not verified because the browser automation tool restricted file navigation. No iOS build or tests were run for these standalone preview artifacts.
