# Stone serif assets,42–45

The four standalone2200×1050 wordmarks are transparent SVG/PNG. Icons are opaque1024×1024 SVG/PNG. Every photograph is embedded in the SVG; no network or fonts are required.

42:34 family,New York Medium;paper icon with signal base.
43:36 family,New York Medium;ink icon with no base.
44:34 family,New York Bold;signal icon with no base.
45:36 family,New York Bold;ink icon with signal base.

Source34 and36 are byte-identical copies of the previously approved transparent PNGs. Family A is isolated nondestructively with a native SVG viewBox. Its pixels,faces and child are unchanged. The lettering uses exact New York outlines from05. The face texture is a reflected/repeating crop of actual chiseled stone from the matching source base. Native SVG side planes and edge lighting add shallow relief. The foundation is the photographed35 base, color-mapped toward Astir signal#F05A3C while preserving texture. ONENESS uses exact serif paths with an engraved effect at the far right. No OCEAN PARK is included in the core lockup.

All outputs were inspected at full size and icons at180/64/48px. Alpha validation and source-copy checks are saved beside this file. Prior rounds were not modified.
