## Affected Pages/Routes

- Profile → Recent activity — a newly saved/check-in event must remain visible
  when the account has multiple records for the same physical place.
- Profile summary counts — Been and Wanna count unique physical places while
  Check-ins count every distinct visit across duplicate records.

## Key Interactions to Verify

- Open Profile after saving a place that already has an older same-place record;
  the newest check-in appears first.
- Reopen or refresh Profile; the activity order and counts remain unchanged.

## Edge Cases

- Multiple same-owner records with visits attached to different records.
- Repeated local/server representations of one visit are counted once.
- A stale Wanna record for a place with a Been record does not add a second
  current-place count.
- Legacy Been records without visit rows still contribute one check-in.

## Critical Paths

- Save/check in → hosted calendar refresh → physical-place grouping → Profile
  Recent activity displays the new visit.
- Duplicate physical-place rows → Profile stats report one Been place and all
  distinct check-ins.
