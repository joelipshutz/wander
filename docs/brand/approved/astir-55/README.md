# Astir direction 55 exports

Joe approved the warm family statue and full-width detached base composition in direction 55 (REC-475). Joe selected **Signal** on September 10, 2026. The Signal app PNG is the canonical production artwork; Oxide is preserved as an unselected exploration.

Each palette has a 1024 × 1024 app-icon PNG and matching Instagram PNG. All are opaque RGB, square, and unmasked. The PNGs were losslessly re-encoded only to remove an all-opaque alpha channel; every RGB pixel matches the original approved export. `provenance.json` records the original and repository SHA-256 hashes.

The artwork comes from the preserved Astir round 08 exploration: the warmed direction 36 family statue on ink-black, floating over a full-width textured base with ONENESS at the right. Signal uses the app’s coral base treatment; Oxide uses the deeper red base treatment. Preserve the statue, framing, air gap, inscription, and texture.

The Signal app PNG is copied byte-for-byte to `Wander/Resources/AppIcon.icon/Assets/astir-statue-55-signal.png` and the fallback 1024 px master. Run the existing master and rendition generators to synchronize the asset catalog. `../../recme-app-icon.md` remains the production icon contract.
