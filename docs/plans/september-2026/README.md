# September 2026 roadmap

The proposal for Joe and Ryan: Astir 001, the app's 30-friends gate, the brand
system, and Rachel's enablement. This is the reviewed planning artifact, not a
claim that its planned work has shipped. Dates and forecasts remain proposals.

## Open the roadmap

- Open [september-roadmap.html](september-roadmap.html) in a browser after
  pulling or downloading this folder. No server or installation is needed.
- Use [september-roadmap.pdf](september-roadmap.pdf) for easy viewing or printing.
- Use [daily-checklists.pdf](daily-checklists.pdf) for one printable page per day,
  or [daily-checklists.html](daily-checklists.html) for the browser version.
- The [survey question bank and follow-up process](astir-beta-feedback-survey.md)
  has [HTML](astir-beta-feedback-survey.html) and
  [PDF](astir-beta-feedback-survey.pdf) review copies. These local copies do not
  collect responses.

Keep this folder together so the deck's local companion links continue to work.
The deck uses Left/Right arrow keys and the on-screen navigation controls.

includes print styles and can be exported through the browser's Print → Save as
PDF flow. Preserve all 24 roadmap slides and verify print pagination. The PDF
copy in Drive should be updated in place to keep its shared link stable.

these artifacts. Packaging and documentation policy are tracked in REC-466.
