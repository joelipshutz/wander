# Astir Events — internal requirement audit

September 14, 2026. Source-fidelity checkpoint for the current product draft and wireframe board. **The audit is complete; the full gstack design review remains in progress.** This is not approval of operating proposals, an engineering specification, an app test, or evidence of release readiness.

## Audit contract

Start with original wording, join each letter answer to its exact question/options, and apply later explicit amendments. A prior assistant summary or a screenshot label cannot approve a new rule. Every requirement below records its authority, source and coverage. Every current frame has a requirement trace. Coverage describes the artifact; it does not imply backend enforcement.

The working sequence is: event link → App Clip or equivalent browser RSVP → Apple/Google → missing name/phone and SMS verification → confirmed RSVP with optional download offer and ongoing texts → recognized confirmed guest-list/RSVP management in the current surface → later download and shortened setup for the entry QR → recorded door admission → published recap notice/text → explicit personal event check-in → attendee recap → normal map → collapsed event card → expanded event and canonical place history. The invented recommendations detour has been removed.

The September roadmap remains the context: internally lock Astir 001, reach 30 friends with a usable beta, and establish the brand/content/list workflow within Joe and Ryan's capacity. The event may be in October. This audit changes neither the roadmap nor its dates. Current public app/Clip availability is not established here; the user selected it as a live-Events prerequisite.

## Maintenance rule

Before changing the spec or a flow, identify affected requirement IDs and their source authority. A new instruction updates those rows and marks superseded rules; an assistant recommendation stays proposed. Rebuild the crosswalk, verify the affected transitions, and update the actual findings rather than relying on screen counts or a previous passing check. Never reopen settled decisions from an older note.
