# Astir Events — failure handling contract

Planning only. Every row describes a failure the implementation must handle, its planned test coverage and what a person should observe. **No Events handler or test exists merely because it appears here.** The full [121-case map plus 24 technical risk groups](test-review/coverage-map.md) supplies the concrete future test paths/assertions. References below are case IDs, not passing runtime results.

**Planning audit result:** every listed failure path has both a planned test reference and an explicit handling/visible-state requirement. Zero *unmapped silent-failure planning gaps* remain in this table. This is not zero runtime risk: the Events tests and handlers are still unimplemented/unverified. Conditional product policies must be resolved before their exact error copy/actions are treated as the release baseline.
